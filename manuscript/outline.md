# Title candidates
- Do local vegetation shocks propagate through mobile food webs? A spatiotemporal test in the Serengeti
- Trophic shockwaves: delayed remote predator responses to localized vegetation anomalies

# One-sentence claim
Local vegetation shocks generate delayed, connectivity-structured carnivore responses at sites distant from the shock origin.

# Abstract skeleton
Background / gap -> data (225 cameras, 2010-2013, MODIS 6.1) -> event-study + distributed-lag connectivity comparison -> result magnitude/timing -> robustness -> implication.

# Introduction
1. Environmental perturbations are spatially localized.
2. Mobile consumers connect distant ecosystems.
3. Trophic effects may therefore propagate with delay.
4. Empirical evidence for such propagation is limited.
5. This study tests existence, speed, reach, and network dependence.

# Results (planned order)
1. Vegetation shocks -> 2. herbivore responses -> 3. spatial redistribution ->
4. remote predator response -> 5. network vs geography -> 6. robustness/falsification.

# Discussion
Ecological shock propagation; network topology; buffering by diet breadth;
conservation/forecasting implications; limits of observational inference.
